研报摘要是券商的内容，网站和代码仓库里只放统计结果和出处，不转载原文。

模型和花费

  • 检索用本地运行的 BGE-M3，不花钱。
  • 大模型都走 OpenRouter：Llama 3.1 8B 给 5.7 万篇摘要打标签；qwen3.8 生成评测题和作答；qwen3.7 / qwen3.8 拆研究计划。
  • 每次调用都记账，有总预算保险丝；全部调用合计 0.58 美元。

规则怎么定

评测的判定规则、模型和提示词的选型规则、上线闸门的阈值，都在看结果之前写定。事后改过的有三处，都写明了原因、留了旧结果：

  1. 上线闸门补了「大模型知识截止日」一项；
  2. 检索评测的泄漏计数写错过，把正常查询找回的标准答案也算成了泄漏；
  3. 作答核验把查询日期里的数字当成「没有出处」。

不能外推的地方

  • 检索和作答的评测题由模型按研报生成，问法比真实研究员整齐。
  • 需求拆解只有 30 道题，只够看出大的差别。
  • 行业景气的样本不到 5 年；回测不代表未来表现，这里也没有任何实盘结果。
  • 摘要里的观点是券商的，这个项目检验的是检索、转述和上线流程，不检验观点本身对不对。

代码

Python，包括 MCP 服务（7 个工具）、需求拆解、检索、上线闸门和评测脚本，40 个离线测试。代码整理后放到 GitHub。
