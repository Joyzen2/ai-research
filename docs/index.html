先证明自己没偷看未来。

研究员提一句需求，系统把它拆成研究计划，在当时已经入库的研报里取证、跑回测，最后按事先写定的 12 项标准出一张上线评审单。拿我自己的指增、文本因子和行业景气来试：信息比最高的那一版，正是闸门否掉的那一版。

看上线闸门发邮件

研究问题

大模型做投研，最危险的不是答不上来，而是三件看起来没问题的事：检索到了当时还没发出来的研报；模型凭记忆说出了它不该知道的结果；回测从十几个版本里挑了最好看的那个。这三件事都会让回测更漂亮，上线以后却不成立。

所以我把投研流程拆成可以检验的几步，每一步都量化它有没有偷看未来、结论能不能复现，再用一道事先写定标准的闸门，决定一条研究结论能不能上线。

研报
57,143 篇券商研报摘要，切成 19 万个片段，每段都带入库时刻
闸门
12 项检查，阈值在看结果之前写定；审计了 20 个候选
评测
64 道检索问答题，30 道需求拆解题，每个选择都按事先写定的规则定
花费
全部大模型调用合计 0.58 美元

三个发现

检索不偷看未来

研报按东财的入库时刻（精确到秒）才能被检索到，过滤放在打分之前。64 道按研报出的题、768 次检索，没有一次返回查询时点之后的研报；向量加关键词的混合召回最好，MRR 0.74。

在检索问答里看

把规则写进提示词，比换模型管用

30 条模糊需求、每条跑 3 次：把今天的日期、时点换算规则和候选清单写进提示词，研究计划完全正确的比例从 40% 升到 93%（McNemar p = 0.0004）。换更贵的模型只多 10 个点、不显著，按规则留用便宜的。

在需求拆解里看

闸门否掉了最好看的那版

加了 Qwen 3.7 文本因子的中证500 指增信息比最高，但模型知识截止日之后只有 5 周回测，排除不了它记得未来，判不通过。大模型读研报摘要做的行业景气年化超额 7.7%，超额都在模型截止日之后，可 t 值只有 1.72，只够放进观察池。

在上线闸门里看

三部分

  • 检索问答
    研报检索与问答：只用当时已入库的研报

    向量加关键词混合召回，检索前按入库时刻过滤；回答逐句标出处、代码核对数字，时点陷阱下没有说漏一个未来的数字。

  • 需求拆解
    需求拆解与 MCP 工具：模型只负责拆计划

    研究计划用 JSON Schema 描述、按数据字典校验，执行走固定流程；7 个 MCP 工具；提示词和模型都用 A/B 测试来选。

  • 上线闸门
    上线闸门：12 项检查，阈值事先写定

    显著性、紧缩夏普、过拟合概率、成本、安慰剂、大模型知识截止日、风控阈值和回测审计；20 个候选里没有一个直接通过。
